# Sales Analytics Dashboard

## Overview

The **Sales Analytics Dashboard** is an end-to-end data analytics project that transforms raw sales data into meaningful business insights. The project demonstrates the complete analytics workflow, including **data cleaning, SQL analysis, KPI generation, and interactive dashboard development**.

Using **Python**, **Pandas**, **MySQL**, and **Power BI**, the dashboard enables users to monitor sales performance, identify trends, analyze customer behavior, and support data-driven business decisions.

---

# ✨ Features

- Data Cleaning and Preprocessing using Python
- SQL-Based Business Analysis
- Interactive Power BI Dashboard
- KPI Monitoring
- Customer Sales Analysis
- Product Performance Analysis
- Regional Sales Analysis
- Monthly Sales Trends
- Category-wise Sales & Profit Analysis
- Business Insight Generation
